# Week 6 — Chapter 6 Selecting Employees and Placing Them in Jobs

> 本章聚焦于**最小化员工甄选与安置中的错误**以提升公司竞争地位，以及任何甄选方法都应满足的**五项标准**，并依据这些标准评估若干常见甄选方法。雇佣决策关乎找到与工作及组织契合的人；组织的人员甄选决策对其生存、适应与成长能力至关重要。当组织面临紧张的劳动力市场，或必须与同行业其他组织争夺人才时，甄选决策尤为关键。

---

## 1. 甄选过程（Selection Process）

- **人员甄选（Personnel Selection）**：组织就是否允许某人加入组织做出决策的过程。
  - 甄选始于通过招募识别出的候选人。
  - 它试图把人数缩减至最有资格执行现有工作的人。
  - 它以被选中的人被安置到组织的岗位上而结束。

### 1.1 甄选过程中的术语
| 术语 | 含义 |
| --- | --- |
| **申请者（Applicants）** | 申请该职位的人 |
| **候选人（Candidates）** | 能满足职位**最低要求**的人 |
| **入围者（Finalists）** | 能**完全满足**职位要求的人 |
| **录用接受者（Offer receivers）** | 能收到录用通知的人 |

### 1.2 甄选过程的步骤（Figure 6.1 / 备注）
1. HR 专业人士审查收到的申请，看哪些符合工作的基本要求。
2. 对符合基本要求的候选人，组织实施测试并审查工作样本，以评定候选人的能力。
3. 能力最好的人被邀请到组织参加一次或多次**面试**（主管与团队成员常参与此阶段）。
4. 对排名前几位的候选人，组织应**核查推荐信并进行背景调查**，以核实信息是否正确。
5. 主管、团队及其他决策者选出接受录用的人。
6. 某些情况下，候选人可就薪资、福利等与组织协商。
7. 若候选人接受工作，组织将其**安置**到该职位。

### 1.3 自动化与技术在甄选中的应用
一条简单的在线职位发布可能在一天内产生数百份简历。许多雇主通过技术手段自动化招聘流程中的重复性任务来应对，如**申请人跟踪系统（ATS, applicant tracking systems）**、**AI**、**机器人流程自动化（RPA, Robotic Process Automation）**，来处理筛选简历、安排面试、发送自动消息等任务。

### 1.4 甄选流程的战略设计
- 组织应创建**支持其工作描述**的甄选过程。
- 甄选过程的设置方式应能让组织识别出具备必要 **KASOs** 的人。
- 这种**战略性甄选方法**要求有办法衡量甄选工具的有效性。

### 1.5 成功甄选方法的五项标准
一个成功的甄选方法：
1. 提供**可靠**的信息（reliable）
2. 提供**有效**的信息（valid）
3. 能**推广**适用于候选人（generalizable）
4. 具有**高效用**（high utility）
5. 使用**合法的**甄选标准（legal selection criteria）

### 1.6 构念（Construct）
- **构念**：概括一组相关现象或对象的抽象概念。
- 例如：**诚实（Honesty）** 是一个构念，不能直接观察，但对理解、描述或预测人类行为很有用。
- 其他例子：领导力、开放心态、自尊、自我导向/他人导向、外向性等。

### 1.7 信度（Reliability）
- **信度**：测量免于**随机误差（random error）**的程度。
- 可靠的测量在相同条件下、由不同评估者重复使用时，会产生**一致的结果**。
- 组织使用统计检验来比较不同时间的结果。

### 1.8 效度（Validity）
- **效度**：某项测量（如测试分数）上的表现与该测量旨在评估的内容（如工作绩效）相关的程度。
- **衡量效度的三种方式：**
  1. 效标关联效度（Criterion-related）
  2. 内容效度（Content）
  3. 构念效度（Construct）

### 1.9 效标关联效度（Criterion-related validity）
- 基于**测试分数与工作绩效分数之间存在显著相关**来证明效度的一种效度测量。
- **相关（Correlation）**：两组数字相关的程度。
- **相关系数（Correlation coefficients）**：范围从 **-1 到 1**
  - **-1** = 完全负相关
  - **0** = 完全没有相关
  - **1** = 完全正相关
- 达成效标关联效度的两种研究：

| 类型 | 说明 | 数据收集时点 |
| --- | --- | --- |
| **预测效度（Predictive Validation）** | 使用所有申请者的测试分数，考察分数与被雇用者**未来**绩效之间的关系 | 效标数据（结果）在预测变量**之后**收集 |
| **同时效度（Concurrent Validation）** | 对**目前担任该工作**的人施测，然后将其分数与现有的工作绩效测量进行比较 | 效标数据与预测变量数据**同时**收集 |

### 1.10 内容效度（Content Validity）
一项测试在多大程度上**充分覆盖其旨在测量的构念的所有相关部分**。

### 1.11 构念效度（Construct Validity）
测试在多大程度上**测量了它声称要测量的东西**。即测试高分与构念（如智力、领导能力）高水平之间的一致性。

> 例：研究者开发一种新工具来测量受访者的**攻击性**水平，该工具的构念效度就是它实际评估的是攻击性、而非自信或社会支配性等的程度。

### 1.12 可推广性（Ability to Generalize）
可推广的甄选方法不仅适用于该方法最初开发时的条件——工作、组织、人员、时期等，也适用于其他组织、工作、申请者等。

### 1.13 实用价值（Practical Value）
- 有效、可靠且可推广，会为甄选方法增加价值。
- 另一个考量是使用该甄选方法的**成本**。
- 甄选方法的成本应显著低于雇用新员工的收益。
- 能提供大于其使用成本的经济价值的方法，被称为具有**效用（utility）**。

### 1.14 候选人的隐私权（Candidates' Privacy Rights）
- 甄选过程中收集的信息可能包含员工认为**保密**的信息。
- 当求职者在**网上**提供信息时，这尤其值得关注。
- 雇主应仅在**安全的网站**上收集数据。

## 2. 求职申请与简历（Job Applications and Résumés）

- **申请表（Application Forms）**：从申请者处收集基本数据的**低成本**方式。确保组织获得某些标准类别的信息：
  - 联系信息
  - 工作经验
  - 教育背景
  - 申请者的签名
- **简历（Résumés）**：
  - 由申请者**掌控**信息
  - 是廉价的起点
  - 应依据**工作描述的要素**来评估
- **推荐信（References）**：
  - 可为电话或书面
  - 存在**偏误**——员工会选择那些会为自己说好话的人
  - 通常在候选人成为该职位的**入围者**时才核查
- **背景调查（Background Checks）**：
  - 核实以往雇佣与教育经历
  - 驾驶记录
  - 犯罪背景调查等

## 3. 雇佣测试与工作样本（Employment Tests and Work Samples）

- **能力倾向测试（Aptitude tests）**：评估一个人**学习或获得**技能与能力的效果。
- **成就测试（Achievement tests）**：测量一个人**现有**的知识与技能。

**常见类型：**
雇佣测试与工作样本包括：体检（Medical Examinations）、工作样本（Work Samples）、人格量表（Personality Inventories）、诚实测试（Honesty Tests）、药物测试（Drug Tests）、工作绩效测试（Job Performance Tests）、认知能力测试（Cognitive Ability Tests）、身体能力测试（Physical Ability Tests）。

### 3.1 身体能力测试（Physical ability tests）
- **身体能力（Physical abilities）**：测量肌肉力量、心血管耐力与动作质量。
- **心理运动能力（Psychomotor abilities）**：测量**思想与身体运动**的关联。例如：反应时间、手臂—手部稳定性、控制精确度、手部或手指灵巧度。
- **感觉/知觉能力（Sensory/perceptual abilities）**：评估**检测与识别环境刺激**的能力。例如：**明尼苏达文书测试（Minnesota Clerical test）**。

### 3.2 认知能力测试（Cognitive Ability Tests）
- 即 **IQ 测试**
- 包含：言语技能、定量技能、推理能力
- **效度良好**
- 可能对**非裔美国人**产生**不利影响（adverse impact）**

### 3.3 工作绩效测试 / 工作样本
- 评估**实际绩效**而非工作知识。
- 要求候选人执行某些关键任务以测试其能力——**最昂贵**。
- **绩效测试（Performance test）**：测量个人在工作中实际做了什么，如**实习（internship）**、**试用期（probationary periods）**。成本更高，但是**更好的预测指标**。
- **工作样本（Work samples）**：捕捉工作的**部分**内容（如运动或言语方面）。
- **评价中心（Assessment center）**：一组多种甄选方法的集合，用于评估**管理潜力**。

### 3.4 Table 6.3 人格量表测量的五大人格维度

| 维度 | 特征 |
| --- | --- |
| **外向性（Extroversion）** | 好交际、爱群居、果断、健谈、富有表现力 |
| **情绪稳定性（Emotional stability）** | 情绪稳定、不抑郁、有安全感、满足 |
| **宜人性（Agreeableness）** | 有礼貌、信任他人、性情温和、宽容、合作、宽恕 |
| **尽责性（Conscientiousness）** | 可靠、有条理、坚持不懈、细致、成就导向 |
| **经验开放性（Openness to experience）** | 好奇、富有想象力、艺术敏感、心胸开阔、爱玩 |

### 3.5 诚实/诚信测试（Honesty Tests / Integrity Tests）
- 用于**防止偷窃**或其他不受欢迎的职场行为。
- 例如用于：出纳员、收银员、保安、警察。
- **效度合理（Reasonable validity）**。
- **局限：** 申请者可能**伪造**其回答；**具争议性**。

### 3.6 药物测试（Drug Tests）的施测规则
- 对所有申请同一工作的人**系统性地**施测。
- 对涉及**安全隐患**的工作使用药物测试。
- 将结果报告寄给申请者，并附上如何对结果提出申诉、以及在适当时如何重测的信息。
- 通过**保密**结果来尊重申请者的隐私。

## 4. 甄选决策（Selection Decisions）

| 模式 | 定义 |
| --- | --- |
| **多重障碍模型（Multiple-Hurdle Model）** | 通过在甄选过程的每个阶段**淘汰**一些候选人，从而达成甄选决策的过程 |
| **补偿模型（Compensatory Model）** | 一种甄选决策过程，其中某一类评估的**极高分数可以弥补**另一类的低分 |

### 录用沟通
当候选人被选中后，组织应向候选人传达录用通知。录用通知应包含：
- 工作职责（Job responsibilities）
- 工作安排/日程（Work schedule）
- 薪酬水平（Rate of pay）
- 开始日期（Starting date）
- 其他相关细节
